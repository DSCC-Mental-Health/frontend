# DSCC Mental Health — Mobile

React Native app built with [Expo](https://expo.dev) (SDK 57) and
[Expo Router](https://docs.expo.dev/router/introduction/).

## Getting started

```bash
npm install
npm run -web
```

## Backend

The API lives in the[`backend`](https://github.com/DSCC-Mental-Health/backend)
repo (Express + Supabase).
